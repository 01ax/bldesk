# Network map
Use Map to inspect the active account's topology: Internet, load balancers, regions, private networks and servers. Select a server to inspect it.

## Read the relationships
Links show resource relationships, not measured packet flows, throughput or proof of connectivity. Use reachability checks and Usage for those questions. The IPv4 audit helps you inspect allocation, not guest routing.

## Navigate and export
Use the map's zoom and fit controls to inspect a dense fleet. Export SVG or PNG when you need a static inventory. An export can expose server names and addresses; review it before sharing or attaching it to a ticket.

Desktop application zoom is separate from map zoom. If controls are too large, use [the bounded desktop zoom shortcuts](help:shortcuts#zoom), then fit the map again.
